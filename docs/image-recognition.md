# 图片收发与“查看原图”

集成版仍发送微信**图片消息**。内置 Native 已修复原图被限制为 65,520 字节及单块上传的问题；不再把标准 `Image` 当文件发送。

## 输出图片

| 层级 | 行为 |
| --- | --- |
| AstrBot → 微信消息适配器 | 标准 Image，最多 10 MiB，校验后原样上传 bytes/本地文件/公网 URL 内容 |
| JPEG original | 完整保留源 JPEG 的字节、尺寸和 SHA-256，不重新编码 |
| PNG 等 original | 转为完整尺寸高质量 JPEG；优先质量 98，超限时逐步降至 90，不缩小尺寸 |
| standard / thumbnail | 继续准备压缩预览图，正常显示为微信图片 |
| CDN 原图上传 | 沿用现有上传字段，按 65,536 字节分块，逐块确认、检查文件 ID 与完整长度 |

支持尺寸仍受 Native 的最大边长 8192、像素 64 MP、解码内存和来源大小限制。PNG 转 JPEG 不是无损格式保留，透明背景也不会保留；已模糊的业务源图不会恢复细节。

预览图可能仍较小，点击“查看原图”才请求完整尺寸副本。JPEG 字节保留、大图分块重组/解密、长图与大尺寸图像已通过源码级自动测试。手机端实际接收与显示仍需要真实账号验收，不以单元测试代替收件端验证。

安装完整集成包后，在“微信管理”重新扫码、一键接入新平台。旧的外部 Native 机器人仍使用旧引擎，无法获得内置补丁；旧微信消息也不会被更新。相关补丁、固定版本、许可和重建方法见 [Native 说明](../native/README.md)。

## 接收与识别

收到的图片转换为标准 AstrBot `Image`，识别使用机器人选择的模型或业务插件。群聊是否唤醒由 AstrBot 决定；适配器不添加默认描述提示词。

明确引用图片时保留文字、引用及可取得的图片，不按“看刚才的图片”等关键词自动关联上一张。媒体读取失败只记录错误，引用正文仍交给框架；已撤回的消息继续保护来源。
